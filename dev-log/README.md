# 开发日志

记录每个工作日的开发进展，保持项目推进透明、可追溯。

## 规则

- 每个工作日一个文件：`YYYY-MM-DD.md`（如 `2026-08-27.md`）。
- 每次工作会话结束时，更新当日条目（这是 CLAUDE.md 中的硬性工作纪律）。
- 内容分四块：

  | 块 | 说明 |
  | --- | --- |
  | 今日完成 | 用 `- [x]` 列出已完成事项 |
  | 待办事项 | 用 `- [ ]` 列出未完成事项，完成后勾选 |
  | 阻塞与风险 | 阻碍推进的问题、风险点 |
  | 明日计划 | 下一次工作要做的事 |

- 新增日志时先复制 `TEMPLATE.md`。
